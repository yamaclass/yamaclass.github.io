ITパスポート試験
## 令和7年度 問98 (テクノロジ系)

4個の要素から成るデータの並びを、次の手順を繰り返して昇順に整列するとき、整列が終了するまでに(1)から(3)の一連の手順は、何回実行されるか。ここで、最初はデータの並び全体を整列対象とする。

データの並び：[27, 42, 33, 12]

〔手順〕
<ol>
    <li>整列対象中の要素の最大の値を選び、最後の要素と入れ替える。</li>
    <li>最後の要素を整列対象から外す。</li>
    <li>整列対象に要素が1個以上残っていれば、(1)から(3)の一連の手順を実行する。残っていなければ、整列完了なので終了する。</li>
</ol>

<ol class="aiueo">
  <li>2</li>
  <li>3</li>
  <li class="ans">4</li>
  <li>5</li>
</ol>

***

やや変則的な選択ソートのアルゴリズムであり、データの並びの最後尾から降順に並び替えることで、最終的に昇順に整列できる。与えられたデータの並びにたまたま既に整列済みの部分であっても、実質的に入れ替え処理がないだけで、最大値の検索や最後の要素の除外は毎回行われることに注意したい。

推移は下記のとおりである。整列対象から外れた部分を太字にしている。

| 回数 | データの並び | 操作対象の数 |
| :-----: | :-----: | :----- |
| 0 | [27, 42, 33, 12] |   |
| 1 | [27, 12, 33, <b>42</b>] | 42（12と入れ替え） |
| 2 | [27, 12, <b>33, 42</b>] | 33（最大かつ最後の要素なので実質的に入れ替えはない） |
| 3 | [12, <b>27, 33, 42</b>] | 27（12と入れ替え） |
| 4 | [<b>12, 27, 33, 42</b>] | 12（最大かつ最後の要素なので実質的に入れ替えはない） |

**4**回目に手順(3)を実行した際に、整列対象に要素は残っていないので終了する。

プログラム例
<pre>
int arr[] = {27, 42, 33, 12};
int n = 4;  // 要素数
int count = 0;  // 手順の回数
for (int end = n; end > 0; end--) {
    // 最大値を探す
    int maxIndex = 0;
    for (int i = 1; i <= end; i++) {
        if (arr[i] > arr[maxIndex]) {
            maxIndex = i;
        }
    }
    // 最大値と最後の要素を交換
    int temp = arr[maxIndex];
    arr[maxIndex] = arr[end];
    arr[end] = temp;
    // カウントを増やす
    count++;
}
printf("%d 回", count);
</pre>

このような疑似プログラミング言語に関する問題は毎年数問出題される。
